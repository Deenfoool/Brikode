# Third-party licenses

The bootstrap Pages shell currently ships without bundled third-party JavaScript dependencies.

Planned editor/runtime dependencies must be reviewed before they are added. Current candidates:

- **Blockly** — Apache License 2.0  
  https://github.com/google/blockly/blob/master/LICENSE
- **Monaco Editor** — MIT License  
  https://github.com/microsoft/monaco-editor/blob/main/LICENSE
- **JSZip** — MIT or GPLv3 dual license; Brikode should use it under MIT terms if adopted  
  https://github.com/Stuk/jszip/blob/main/LICENSE.markdown

When a dependency is actually bundled or distributed, this file must be updated with the version, license and required notices.
